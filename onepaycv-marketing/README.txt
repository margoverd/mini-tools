# OnePayCV Marketing Tracker

Открой `index.html` в браузере. Прогресс хранится в localStorage этого браузера и не требует интернета.

Функции:
- 4 недели / 28 дней плана
- отметка выполнения
- общий прогресс
- XP и уровни
- серия выполненных дней
- награды
- блок «Сегодня»
- автоматическое сохранение
- адаптивный мобильный дизайн
- светлая/тёмная тема через системные настройки
